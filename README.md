# Sk Mahaboob Basha - Portfolio Website

My personal portfolio website built with HTML, CSS, and Vanilla JavaScript. It showcases my skills, Frontend projects, and newly completed Full Stack projects.

## 🔗 Live Demo
You can view the live website here: [https://basha-k72.github.io/CodeAlpha_Portfolio/](https://basha-k72.github.io/CodeAlpha_Portfolio/)

## 🚀 Features
- Hero section with dynamic typing animation
- About Me section
- Skills grid (Frontend & Backend)
- **Projects Showcase:** Displays both Frontend and Full Stack projects with live demo links.
- Contact section with email, phone, LinkedIn, GitHub
- Smooth scroll and scroll-reveal animations
- Fully responsive design

## 💻 Tech Stack
- **Frontend:** HTML5, CSS3 (Grid, Flexbox, Animations), Vanilla JavaScript (IntersectionObserver API)
- **Full Stack (Featured Projects):** Node.js, Express.js, MongoDB, JWT

## 📂 Featured Projects
1. **E-commerce Store:** Full Stack app with JWT Auth, Shopping Cart, and MongoDB.
2. **Connect - Social Media App:** Mini social media platform with posts, likes, and comments.
3. **ProjectHub - Management Tool:** Trello-like board to manage projects and track tasks.
4. **Image Gallery & Calculator:** Vanilla JS frontend projects.
