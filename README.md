# CodeAlpha_Portfolio

My personal portfolio website built with HTML, CSS, and JavaScript.

## Features
- Hero section with typing animation
- About Me section
- Skills grid
- Projects showcase (Image Gallery, Calculator, Arduino Project)
- Contact section with email, phone, LinkedIn, GitHub
- Smooth scroll and scroll-reveal animations
- Fully responsive design

## Tech Stack
- HTML5
- CSS3 (Grid, Flexbox, Animations)
- Vanilla JavaScript (IntersectionObserver API)
